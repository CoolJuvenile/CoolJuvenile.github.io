关于我

CoolJuvenlie

你好，我是 CoolJuvenlie。高中生，爱好是把东西拆开、再想办法让它重新跑起来。

我在折腾什么

  • 嵌入式：ESP32 / ESP32-S3、STM32，从点灯到驱动 OLED 做动画；
  • 底层：Linux 内核编译与裁剪，Android 设备的 boot 镜像打包；
  • Web：静态博客、自动化脚本，以及各种「给自己用」的小工具。

我的项目大多放在 GitHub 上，从 ESP32 的 WiFi 测试工具到给 Redmi Note 11T 编的内核，都是边学边写的产物。写得不一定漂亮，但都能跑。

技能栈

方向在用的东西
语言C / C++ / Python / JavaScript / 一点点 Kotlin
硬件ESP32-S3、Arduino、SSD1306、各种传感器
系统Linux、Android 内核、Buildroot
工具Git、PlatformIO、Arduino IDE、VS Code

这个站

站点用 Hexo + AnzhiYu 主题生成，托管在 GitHub Pages 上，因此不需要备案。域名就是仓库名，改完 push 上去几分钟就能看到效果。

左下角那只 Live2D 看板娘是 DS鲸鱼娘（DeepSeek 大肥鱼），渲染用 oh-my-live2d + 官方 Cubism Core，模型和运行时全部放在本地，不依赖第三方 CDN。它会跟着鼠标看，偶尔说两句话，觉得烦可以点菜单让它睡一会儿。
